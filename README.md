# ict1011-meds_reminder
this is a github repository for ict1011 group project


software to install: Arduino IDE

libraries to install (in Arduino): 
- RTCZero by Arduino
- WiFI101 by Arduino
- TinyScreen by TinyCircuits
- Wireling by TinyCircuits

start website backend with
```npm start```
or
```npm.cmd start``` (if there is an error)
