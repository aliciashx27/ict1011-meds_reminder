How it works

1. Add or edit medication details on this website.

2. The website sends the information to your cloud backend.

3. Your TinyCircuits device retrieves the latest medication information through Wi-Fi.

4. The device updates its screen and reminder schedule.

Developer information

Backend API settings are configured in the JavaScript section of this HTML file. The backend must provide the API routes used by this website.
